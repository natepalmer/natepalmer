# Nathan Palmer

I'm a computational biologist focused on genome engineering, sequencing analysis, and high-throughput screening. I'm especially interested in problems where experimental design and computational analysis have to be developed together.

Selected projects:

- [CRISPR-ampseq](https://github.com/natepalmer/CRISPR-ampseq) — CRISPR amplicon-sequencing analysis.
- [deepak](https://github.com/natepalmer/deepak) — deep mutational scanning of ADAR2. [*eLife* 75555 (2022).](https://elifesciences.org/articles/75555)
- [lorax](https://github.com/natepalmer/lorax) — long-read variant calling and analysis for protein-engineering screens. [*Nat Biomed Eng* 9, 109–126 (2025).](https://www.nature.com/articles/s41551-024-01245-z)
- [immune-orthogonal](https://github.com/natepalmer/immune-orthogonal) — protein immunogenicity and graph-based orthogonality analysis. [*Nat Biomed Eng* 3, 806–816 (2019).](https://www.nature.com/articles/s41551-019-0431-2)

My recent industry work at Sangamo Tx and CRISPR Tx has also included cloud-deployed sequencing pipelines, genome-wide safety analyses, and computational support for therapeutic programs.
